# YouAre.bot — классификатор «бот или человек»

Курсовой проект по Production ML: для каждого участника диалога предсказать
вероятность того, что это бот. Данные — соревнование
[You Are Bot](https://stackmorelayers.ai/competitions/you-are-bot), метрика — LogLoss.

Весь код проекта — в папке [`project/`](project/): там описание, инструкция
по воспроизведению и результаты экспериментов.

```bash
cd project
./run_experiment.sh   # окружение → тесты → эксперименты в MLflow → реестр моделей → сабмит
```
